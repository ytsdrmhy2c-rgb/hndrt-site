# HN-DRT 공식 홈페이지 (검토용)

GitHub Pages용 HN-DRT 홈페이지입니다. 사용자가 승인한 V2+V3 혼합 디자인을 유지합니다.

## 최초 배포

1. GitHub 저장소 `Settings` → `Pages`에서 Source를 **GitHub Actions**로 선택합니다.
2. 이 저장소의 `main` 브랜치에 `hndrt-site-assets.zip`을 파일 이름 그대로 한 번 업로드하고 `Commit changes`를 누릅니다. 압축을 풀지 않습니다.
3. `Actions` 탭의 `HN-DRT Pages`가 성공하면 `https://ytsdrmhy2c-rgb.github.io/hndrt-site/`에서 검토할 수 있습니다.

`hndrt-site-assets.zip`에는 디자인 CSS, 웹페이지 JavaScript 및 사진 파일만 포함됩니다. 공개 전 임시 로고·사진을 정식 자료로 바꿔야 합니다.

`admin.html` 시연 페이지는 공개 사이트에 배포하지 않습니다. GitHub Pages는 정적 웹사이트이며 관리자 로그인, 사진 저장, 게시물 동기화는 별도 개발이 필요합니다.

**주의**: 이 저장소와 GitHub Pages 사이트는 공개 상태입니다. 개인정보 또는 비공개 운영자료를 업로드하지 마세요.
